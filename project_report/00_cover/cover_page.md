## Abstract *(brief — expand for final submission)*

Zoos manage animals, staff, habitats, feeding, veterinary care, and visitors. When these areas are tracked in separate spreadsheets or disconnected tools, information gaps appear: missed feedings, unclear care assignments, and weak reporting. This project proposes a **unified relational database** for zoo operations. The report documents the development lifecycle: **planning** the need for a single system, **analyzing** user needs as UI page requirements, and **designing** the database conceptually, logically, and physically—including conceptual and physical ER diagrams and the SQL schema.
